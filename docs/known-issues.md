# Известные ограничения и блокеры

| ID | Ограничение | Влияние | Условие закрытия |
|---|---|---|---|
| RADIO-1 | Зависимость от Radio Browser и сети | нет сети — нет обновления | кеш или retry |
| RADIO-2 | Станции часто умирают | нужен `make prune` | регулярная проверка |
| RADIO-3 | Нет unit-тестов | ошибки парсинга ловятся поздно | добавить тесты |
| RADIO-4 | Нет явных rate limits | возможны блокировки API | backoff и лимиты |
| RADIO-5 | Формат cliamp может измениться | плейлист не прочитается | проверка версии cliamp |

## Что делать агенту

1. Не добавляйте секреты и токены.
2. Не выполняйте массовые сетевые проверки без необходимости.
3. При изменении формата сначала обновите README и тесты.
