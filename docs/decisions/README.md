# Архитектурные решения (ADR)

Короткие записи о решениях, которые меняют поведение или правила проекта.
ADR фиксирует **почему**, а не пересказывает код.

## Формат

```text
# ADR-NNNN. Название

- Статус: предложено | принято | заменено | отменено
- Дата: ГГГГ-ММ-ДД
- Связанные: ссылки

## Контекст
## Решение
## Следствия
```
