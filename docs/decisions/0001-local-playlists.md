# ADR-0001. Локальные TOML-плейлисты из Radio Browser

- Статус: принято
- Дата: 2026-11-17
- Связанные: [`../../README.md`](../../README.md), [`../integrations.md`](../integrations.md)

## Контекст

cliamp не хранит каталог станций: он читает локальные TOML-плейлисты.
Станции нужно отбирать по жанрам, проверять с текущей машины и обновлять без
ручного перебора.

## Решение

1. Источник каталога — Radio Browser API.
2. Скрипты заранее собирают TOML-плейлисты в
   `~/.config/cliamp/playlists/`.
3. Каждый поток проверяется с локального интерфейса; VPN не должен
   искажать проверку.
4. `realtime = true` включается для живого радио.
5. Мёртвые станции удаляются через `verify_playlists.py --prune`.
6. Обновление запускается еженедельно в GitHub Actions и вручную.

## Следствия

- cliamp работает без обращения к Radio Browser во время проигрывания.
- Появляется зависимость от сети при обновлении и от доступности станций.
- Нужны `curl`, `iproute2` и Python 3.11+.
- Формат TOML и набор жанров нужно поддерживать при изменениях cliamp.
