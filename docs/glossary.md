# Глоссарий cliamp_radio_local

| Термин | Значение |
|---|---|
| cliamp | Терминальный радиоплеер, для которого собираются плейлисты |
| Radio Browser | Внешний каталог радиостанций |
| TOML-плейлист | Файл `[[track]]` для cliamp |
| `realtime = true` | Переподключение cliamp после паузы или обрыва |
| Жанровый плейлист | До N станций одного жанра |
| Российский плейлист | Станции, расположенные в России |
| Встроенные каналы | Список из `radio.cliamp.stream` |
| `candidates` | Сколько станций проверять до отбора |
| `per-list` | Сколько станций оставить в плейлисте |
| `iface` | Интерфейс, к которому привязаны проверки |
| `prune` | Удаление мёртвых станций из плейлистов |
