# Документация cliamp_radio_local

Карта документации. Начинайте с [`../AGENTS.md`](../AGENTS.md). Статусы:

- **канон** — описывает текущее поведение;
- **текущий** — актуальный статус или ограничения;
- **исторический** — сохранён для контекста;
- **генерируется** — создаётся скриптом, руками не править.

## 0. Первые 30 минут

1. Прочитайте [`../AGENTS.md`](../AGENTS.md): правила, границы, команды.
2. Посмотрите [`status.md`](status.md): что работает и что болит.
3. Запустите минимальные проверки из `AGENTS.md`, раздел 4.
4. Выберите задачу по маршрутизатору.
5. Если что-то сломалось — [`troubleshooting.md`](troubleshooting.md).
