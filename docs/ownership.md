# Зоны ответственности и окружения

## 1. Зоны

| Зона | Ответственный | Что решает |
|---|---|---|
| Продукт | владелец проекта | набор жанров и формат |
| Скрипты | владелец проекта | сборка и проверка |
| Внешние данные | Radio Browser | доступность каталога |
| CI | GitHub Actions | compile, smoke, refresh |

## 2. Окружения

| Окружение | Назначение | Особенности |
|---|---|---|
| Локальное | разработка и сборка | `.venv`, `make` |
| CI | проверки | GitHub Actions |
| Пользовательское | cliamp | `~/.config/cliamp/playlists/` |

## 3. Эскалация

| Вопрос | К кому |
|---|---|
| Формат cliamp | владелец cliamp/проекта |
| Radio Browser | владелец проекта |
| CI и расписание | владелец репозитория |
