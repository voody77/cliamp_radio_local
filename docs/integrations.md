# Внешние интеграции

| Сервис | Направление | Протокол | Авторизация |
|---|---|---|---|
| Radio Browser | исходящий | HTTP JSON | нет |
| cliamp M3U | исходящий | HTTP | нет |
| cliamp playlists | локальные файлы | TOML | файловая система |
| `curl` / `ip` | локальные команды | CLI | нет |

## Поведение

- таймауты и проверка потока — через `curl`;
- привязка к интерфейсу — `--iface`, чтобы VPN не искажал проверку;
- rate limits Radio Browser не заданы явно;
- ошибки сети не кешируются как успешные;
- секретов и токенов нет.
